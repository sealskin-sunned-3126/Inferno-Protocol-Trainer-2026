## 🎮 About the Game

Inferno Protocol is an indie top-down action roguelite developed by Inferno Protocol Team and released in 2024. Players fight through hostile procedurally arranged areas, collect upgrades, manage resources, and build a stronger character during each run.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Inferno Protocol**. This trainer adds optional single-player assistance for combat, progression, and resource management. It can protect the player from incoming damage, improve weapon handling, provide additional ammunition and stamina, and simplify the collection and use of in-game resources.

**Target Audience:** Suitable for players who want to experiment with different builds, reduce repetition, practice combat, or enjoy Inferno Protocol at a more relaxed difficulty. It is intended for offline single-player use.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Infinite Health** — Prevents the player character's health from being depleted during a run.
- **Infinite Stamina** — Keeps stamina available for movement and other actions that consume it.
- **Unlimited Credits** — Keeps the available spending currency from decreasing when used for supported purchases or upgrades.
- **Easy Upgrade Purchases** — Makes supported character and weapon upgrades easier to obtain during progression.
- **Freeze Run Timer** — Stops supported run or mission timing while the option is enabled.

### ⚔️ Combat

- **Unlimited Ammunition** — Provides a continuous supply of ammunition for the currently equipped weapon.
- **No Reload** — Allows weapons to fire without waiting for the normal reload cycle.
- **Rapid Fire** — Improves the firing rate of compatible weapons.
- **One-Hit Kills** — Causes standard enemies to be defeated with a single successful hit.

## 📖 Detailed Feature Guide

### Movement & Exploration

Load into a playable area before activating movement-related assistance. Normal movement remains available through the game's standard controls, while Infinite Stamina supports repeated movement actions without the usual resource limit. Disable the option before returning to menus or changing game states.

### Tools & Inventory

Collect weapons, ammunition, currency, and upgrade items normally unless an inventory option is enabled. Unlimited Ammunition affects supported weapon reserves, while Unlimited Credits applies to supported purchases. Save the game after making important upgrades and avoid changing inventory values repeatedly in menus.

### World & Environment

Explore each procedurally arranged area, collect available resources, and interact with upgrade or purchase points as usual. Freeze Run Timer is intended for active runs and should be disabled before completing objectives, changing areas, or returning to the main menu.

### Combat & Weapons

Enter active gameplay before enabling combat options. Infinite Health protects the player from ordinary damage, Unlimited Ammunition and No Reload reduce weapon resource management, Rapid Fire increases firing speed, and One-Hit Kills speeds up encounters with standard enemies. Some scripted encounters, bosses, or special damage events may not respond to every option.
